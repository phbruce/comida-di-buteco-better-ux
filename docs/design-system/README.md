## Por que esperar?

Porque o pedido foi explícito: **decisões de ADR passam pelo dono do produto antes de implementar**. Implementar tokens em código antes da aprovação seria criar dívida e força inércia em uma decisão que ainda não foi tomada.

## O que fazer agora?

1. Revisar e aprovar (ou solicitar mudanças) nos ADRs PROPOSED.
2. Promover ADRs aceitos para `ACCEPTED`.
3. Abrir trabalho de implementação a partir do plano de cada ADR.
